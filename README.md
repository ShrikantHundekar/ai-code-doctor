# AI Code Doctor 🩺⚡

> **An Advanced Multi-Model AI Code Review, Debugging, Refactoring, and Security Analysis Platform.**

AI Code Doctor is a developer intelligence platform that analyzes code across multiple industry-leading AI models (**OpenAI GPT-4o**, **Anthropic Claude 3.5 Sonnet**, and **Google Gemini 1.5 Pro**) simultaneously. It calculates consensus agreements, highlights discrepancies, diagnoses bugs with root cause explanations, provides goal-driven refactoring, performs SAST security audits, and generates prioritized improvement roadmaps.

## 🚀 Key Features

### 1. 🤖 Multi-AI Code Comparison & Consensus Engine
- **Parallel AI Execution**: Sends code concurrently to OpenAI, Claude, and Gemini in parallel threads using Python's `ThreadPoolExecutor`.
- **Fuzzy Bug Clustering**: Automatically clusters similar bug reports from different providers using semantic string similarity and AST line proximity.
- **Confidence Rating**: Identifies bugs with **High Confidence** (all providers agree), **Medium Confidence** (majority agree), or **Low Confidence** (single provider finding).
- **Algorithmic Disagreement Detection**: Alerts developers when models calculate conflicting Big-O time or space complexities (e.g. $O(n)$ vs $O(n^2)$).
- **Composite Agreement Score**: Computes an aggregate agreement score ($0\% - 100\%$) indicating cross-model consensus.
- **Dynamic Best Provider Recommendation**: Mathematically determines which provider generated the most rigorous critique and highest quality fix without hardcoded provider bias.
- **Multi-AI Fix Switcher**: Side-by-side tabs allowing you to toggle and inspect code fixes generated by OpenAI, Claude, and Gemini.

### 2. 🔍 Comprehensive Code Review & Improvement Plans
- **Detailed Quality Scoring**: Overall code health score ($0 - 100$) broken down into Readability, Maintainability, Performance, and Security.
- **Categorized Issue Breakdowns**: Line-referenced Bugs, Warnings, and Style recommendations.
- **Priority 1–4 Action Plans**: Structured improvement steps (P1: Critical/Bugs, P2: Warnings/Safety, P3: Performance, P4: Style/Docs).
- **Version Tracking (`v1` → `v2`)**: Save and track code revisions across iterations to verify score improvements after applying fixes.

### 3. 🐛 Dedicated AI Debugging Studio (`/debug`)
- Paste problematic code along with runtime error messages and stack traces.
- AI provides **Root Cause Analysis**, explanation of why the failure occurred, a suggested remediation, and a drop-in code diff.

### 4. 📖 Skill-Tailored Code Explanation (`/explain`)
- Select your target skill level:
  - **Beginner**: Conceptual analogies, no jargon.
  - **Intermediate**: Control flow, design patterns, and idiomatic practices.
  - **Advanced**: Memory layout, runtime internals, and computational complexity.
- Includes line-by-line and step-by-step interactive annotations.

### 5. 🛠️ Goal-Driven Code Refactoring (`/refactor`)
- Select specific refactoring goals:
  - Readability & Clean Code
  - Performance & Optimization
  - Maintainability & Strict Typing
  - Reduce Duplication (DRY)
  - Simpler Control Logic
- View before/after code diffs with explanations of architectural changes and expected payoffs.

### 6. 🛡️ SAST Security Vulnerability Scanner (`/security`)
- Audits code against common security pitfalls: SQL Injection, Command Injection, Insecure Deserialization, Hardcoded Credentials, and Unsafe Inputs.
- Displays an **Overall Risk Assessment Meter** (Low, Medium, High, Critical) with impact descriptions and remediations.

### 7. ⚖️ Review & Version Comparison (`/history/compare`)
- Select any two past reviews or version evolutions to compare:
  - Score delta ($\Delta$ Score)
  - Bug count delta ($\Delta$ Bugs)
  - Security vulnerability changes
  - Side-by-side syntax diff viewer

### 8. 📊 Provider Performance History & Analytics
- Track your historical review volume and average scores per provider (OpenAI vs. Claude vs. Gemini vs. Multi-AI) directly on your Dashboard.

## 🧠 How Multi-AI Consensus Works

When a user submits code in **Compare Multiple AIs** mode:

1. **Concurrent Dispatch**: The `ComparisonService` submits requests in parallel using Python's `concurrent.futures.ThreadPoolExecutor(max_workers=3)`.
2. **Partial-Failure Resilience**: If one provider encounters a rate limit or timeout, the remaining successful responses are retained and synthesized.
3. **Bug Clustering Algorithm**:
   - Compares bugs reported by different models.
   - Matches issues where line numbers are within $\pm 2$ lines and normalized title similarity ratio $> 0.45$.
   - Identifies whether the issue has **High Confidence** ($3/3$), **Medium Confidence** ($2/3$), or **Low Confidence** ($1/3$).
4. **Algorithmic Disagreement Check**: Compares Big-O time and space complexities. If OpenAI detects $O(n)$ while Claude detects $O(n^2)$, a **Complexity Disagreement Alert** is triggered.
5. **Weighted Scoring for Best Provider**:
   $$\text{Score}_{\text{provider}} = (0.3 \times \text{Score}) + \min(15 \times \text{Bugs}, 30) + \min(10 \times \text{SecIssues}, 20) + (0.3 \times \text{AvgQuality})$$
   The model providing the most thorough, validated findings is nominated as the recommended solution with a dynamically generated explanation.

## 💻 Tech Stack

### Frontend
- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS with dark mode support
- **Icons**: Lucide React
- **Diff & Highlighting**: Custom syntax diff viewer and code editors
- **Routing**: React Router 6

### Backend
- **Framework**: Python 3.10+ / Flask 3.0
- **Database & ORM**: Flask-SQLAlchemy with auto-schema migration (SQLite default, PostgreSQL ready)
- **Authentication**: Secure HTTP-only cookies / session tokens with bcrypt/scrypt password hashing
- **Concurrency**: Python `concurrent.futures.ThreadPoolExecutor`
- **Validation**: Marshmallow & custom JSON schema validators
- **AI SDKs**: `openai`, `anthropic`, `google-genai` / `google-generativeai`

## ⚙️ Installation & Setup

### Prerequisites
- **Node.js** (v18 or higher) & **npm**
- **Python** (v3.10 or higher)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/AIcode_debugger.git
cd AIcode_debugger
```

### 2. Backend Setup
```bash
# Navigate to backend folder
cd backend

# Create virtual environment (recommended)
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Frontend Setup
```bash
# Return to root directory
cd ..

# Install frontend dependencies
npm install
```

## 🏃 Running the Application

### 1. Start the Flask Backend Server
```bash
cd backend
python app.py
```
*The backend starts at `http://localhost:5000` (Database tables are auto-created and migrated on startup).*

### 2. Start the Vite Frontend Server
```bash
# In a separate terminal in root folder:
npm run dev
```
*The frontend will start at `http://localhost:5173`.*

## 🔐 Environment Variables

Create a `.env` file in the `backend/` directory:

```ini
# Flask Configuration
FLASK_ENV=development
SECRET_KEY=your-super-secret-key-here
PORT=5000

# Database Configuration (Defaults to SQLite if omitted)
DATABASE_URL=sqlite:///ai_code_doctor.db

# AI Mock Mode (Set to true to run fully offline without API keys)
AI_MOCK_MODE=true

# AI Provider API Keys (Required when AI_MOCK_MODE=false)
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GEMINI_API_KEY=AIzaSy...

# Default Provider for single review mode (openai | claude | gemini)
DEFAULT_AI_PROVIDER=openai
```
